Kharcha

Private expense, budget, EMI & Udhar tracker for family and friends. Your data stays on your own phone.
Englishहिंदी

📱 Android phone

Download Kharcha.apk
  1. Tap Download Kharcha.apk (or open the file sent on WhatsApp).
  2. Tap Open. If Android says "For your security, your phone is not allowed to install unknown apps", tap Settings → turn on Allow from this source → go back.
  3. Tap Install. If Play Protect shows a warning, tap More details → Install anyway (the app is shared privately, not from Play Store).
  4. Open Kharcha, type your name, and (optional) set a 4-digit PIN.
  5. Allow notifications when asked, so you get EMI and Udhar reminders.
🔄 Updating: install the new APK over the old one. Do not uninstall first — uninstalling deletes your data.

💻 Laptop or iPhone

Open Kharcha in the browser
  1. Open the link in Chrome, Edge or Safari.
  2. Chrome/Edge: menu ⋮ → Install app. iPhone Safari: Share → Add to Home Screen.
  3. Data is saved in that browser on that device. Reminders show only while the app is open.

💾 Keep your data safe

  1. Android: Kharcha saves a backup automatically every day you use it, in Files → Documents → Kharcha. This folder stays even if the app is uninstalled.
  2. Laptop (Chrome/Edge): Customize → Choose backup folder once. After a browser restart, tap Continue auto-backup when asked.
  3. Once a month, copy the newest file to Google Drive (or Customize → Backup now → Drive) in case the phone is lost.
  4. New phone? Install Kharcha, then Customize → Restore from backup and pick the file.

📱 एंड्रॉइड फ़ोन पर इंस्टॉल करें

  1. ऊपर Download Kharcha.apk दबाएँ (या WhatsApp पर आई फ़ाइल खोलें)।
  2. Open दबाएँ। अगर "unknown apps" की चेतावनी आए तो Settings → Allow from this source चालू करें और वापस आएँ।
  3. Install दबाएँ। Play Protect चेतावनी दे तो More details → Install anyway दबाएँ।
  4. ऐप खोलें, अपना नाम लिखें और चाहें तो 4 अंकों का PIN रखें।
  5. EMI और उधार की याद दिलाने के लिए नोटिफ़िकेशन की अनुमति दें।
🔄 नया वर्ज़न आने पर नई APK पुरानी के ऊपर ही इंस्टॉल करें। पहले अनइंस्टॉल न करें, वरना आपका डेटा मिट जाएगा।

💾 डेटा सुरक्षित रखें

  1. आपका सारा डेटा सिर्फ़ आपके फ़ोन में रहता है, कहीं और नहीं भेजा जाता।
  2. ऐप हर दिन अपने-आप बैकअप Files → Documents → Kharcha फ़ोल्डर में सेव करता है। ऐप हटाने पर भी यह फ़ोल्डर रहता है।
  3. महीने में एक बार सबसे नई फ़ाइल Google Drive में कॉपी कर लें, ताकि फ़ोन खोने पर भी डेटा सुरक्षित रहे।
  4. नया फ़ोन लेने पर ऐप इंस्टॉल करें और Customize → Restore from backup से डेटा वापस लाएँ।

Kharcha does not read SMS, has no ads and sends nothing to any server. Shared privately among family and friends.
